# AI助学动态图片+光标标记讲解系统

## 系统概述

本系统基于 `临时文件.txt` 中三套方案的融合实现：
- **Gemini方案**：热点标记 + 光标准确定位 + 悬浮详解
- **DeepSeek方案**：步骤化教学面板 + 高亮圈 + 自动播放
- **豆包方案**：Canvas交互 + 热点讲解 + 视觉反馈

融合后形成：**左侧图片展示区 + SVG光标标记 + 右侧四段式教学面板** 的完整交互式教学演示系统。

## 快速启动

1. 将 `index.html` 和 `study_teaching_engine.js` 放在同一目录
2. 双击 `index.html` 用浏览器打开
3. 点击「自动播放」或使用键盘方向键开始学习

## 定制教学内容

### 方式一：修改JS配置区（快速入门）

打开 `study_teaching_engine.js`，找到两个全局配置变量：

#### TEACHING_IMAGE_LIBRARY（教学图片库）

每张图包含基本信息和标记点：

```javascript
var TEACHING_IMAGE_LIBRARY = [
  {
    id: "my_001",                    // 唯一标识
    path: "images/my_image.jpg",     // 图片路径（支持URL或本地路径）
    title: "我的教学图片",            // 图片标题
    subject: "数学",                  // 学科名称
    module: "知识点模块",             // 知识点模块
    description: "描述说明",          // 详细描述
    marks: [                         // 预设标记点
      { x: 50, y: 30, label: "标记1说明" },
      { x: 70, y: 60, label: "标记2说明" }
    ]
  }
];
```

#### TEACHING_STEPS（四段式教学步骤）

每个阶段包含多个步骤：

```javascript
var TEACHING_STEPS = [
  {
    stage: "parse",                  // 阶段标识
    stageTitle: "一、解析问题",       // 阶段标题
    steps: [
      {
        title: "步骤标题",
        content: "讲解文字内容\n支持换行",  // \n 表示换行
        cursorX: 50,                 // 光标X坐标（0-100百分比）
        cursorY: 30,                 // 光标Y坐标（0-100百分比）
        ring: null,                  // 高亮圈（null=不显示）
        // 或 ring: { x: 50, y: 30, size: 48 }
        isQuiz: false,               // 是否为闯关步骤
        // quizOptions: ["A.选项", "B.选项", "C.选项", "D.选项"],
        // quizAnswer: 0,            // 正确答案索引（从0开始）
        // quizExplain: "解析文字"
      }
    ]
  }
];
```

## 技术实现关键点

### 1. 动态图片加载

```javascript
// 图片切换通过修改img元素src实现
img.src = newImagePath;
// 利用img.complete检测缓存，onload事件处理新图片加载
```

### 2. SVG光标标记

```javascript
// 光标使用SVG箭头，嵌入在div中
// 通过CSS transition实现平滑移动动画
cursor.style.left = targetX + 'px';
cursor.style.top = targetY + 'px';
// transition: left 0.8s cubic-bezier(...), top 0.8s ...
```

### 3. 高亮圈脉冲动画

```css
/* CSS @keyframes 实现脉冲闪烁 */
@keyframes ringPulse {
  0%   { box-shadow: 0 0 8px rgba(200,149,62,0.4); }
  50%  { box-shadow: 0 0 24px rgba(200,149,62,0.4); }
  100% { box-shadow: 0 0 8px rgba(200,149,62,0.4); }
}
```

### 4. 四段式教学流程

```
解析问题 → 讲解原理 → 变式测试 → 归纳总结
    ↓          ↓          ↓          ↓
  拆解题意    深挖原理    即时闯关    知识归档
```

### 5. 闯关检测逻辑


## 常见问题排查

| 问题 | 原因 | 解决 |
|------|------|------|
| 图片不显示 | 图片URL无法访问 | 检查path路径，使用本地图片 |
| 光标位置不对 | 百分比坐标有误 | 调整cursorX/cursorY值 |
| 闯关无反应 | isQuiz未设为true | 检查步骤配置 |
| 动画卡顿 | 图片过大 | 压缩图片尺寸 |
| 布局错乱 | 浏览器窗口太窄 | 调整窗口宽度(>960px) |

## 开发者学习要点

### HTML层面
- 语义化标签：header/main/section/article/nav/aside/footer
- SVG矢量图标内联绘制
- CSS变量(--var)统一管理配色

### CSS层面
- Grid布局实现三行结构（header/main/footer）和双列（图/文）
- Flexbox实现按钮栏/缩略图/阶段导航
- @keyframes动画定义 + transition平滑过渡
- 媒体查询(@media)响应式适配
- 伪元素(::before/::after)创建装饰

### JavaScript层面
- 构造函数模式封装（var TeachingEngine = function(){}）
- 闭包解决循环绑定问题（IIFE立即执行函数）
- DOM事件系统（click/keydown/resize）
- getBoundingClientRect()获取元素实际位置
- setTimeout/setInterval 异步调度
- requestAnimationFrame 帧同步渲染
